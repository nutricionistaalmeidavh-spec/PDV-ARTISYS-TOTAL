# Agent Windows

Use `install-agent.ps1` para instalar o `woodpecker-agent` e o `plugin-git` no Windows e preparar o clone compartilhado de `utilidades`.

Depois use `start-agent.ps1` para conectar o Agent ao Woodpecker Server usando backend `local`.

O backend local executa comandos diretamente neste Windows; mantenha este Agent restrito aos repositorios ArtiSys confiaveis.
