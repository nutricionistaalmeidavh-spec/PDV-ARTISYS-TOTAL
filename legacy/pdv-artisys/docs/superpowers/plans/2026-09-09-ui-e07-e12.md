# PDV ArtiSys UI E07-E12 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar o shell desktop e as telas definitivas de Início, Balcão, Clientes/Vendedores e Produtos, conectadas ao núcleo E02-E06.

**Architecture:** Electron frameless inicia o servidor local e carrega um renderer estático HTML/CSS/JS. O renderer usa apenas `/api/v1`; nenhuma regra de negócio é duplicada no DOM. Atalhos chamam ações de aplicação e o servidor permanece autoridade de estado.

**Tech Stack:** Electron 39, Node 22, HTML/CSS/JavaScript sem framework, node:test, SQLite via node:sqlite.

**Spec:** `docs/superpowers/specs/2026-09-09-pdv-core-e02-e06-design.md` + referências visuais aprovadas na conversa de 2026-09-09.

## Global Constraints

- Desktop/local-first; sem SaaS ou dependência de internet.
- Banco acessado apenas pelo servidor local.
- Dinheiro em centavos inteiros.
- UI nunca chama SQL diretamente.
- EventBus/outbox continuam responsáveis pelos efeitos pós-venda.
- E07-E12 não implementam fiscal, hardware ou relatórios completos.
