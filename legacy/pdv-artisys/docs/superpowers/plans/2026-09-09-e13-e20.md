# PDV ArtiSys E13–E20 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar Estoque, Caixa, Vendas/Devoluções, Financeiro, Relatórios, Hardware, Impressão e Fiscal sobre o núcleo E01–E12 já validado.

**Architecture:** O servidor local continua autoritativo sobre SQLite e regras de negócio. UI acessa apenas API local/IPC estreito; efeitos externos de impressão/fiscal usam EventBus/outbox e idempotência. Código reaproveitado de PDVNexus e CLINICASMEDICAS será adaptado a centavos inteiros, segurança atual e contratos do PDV ArtiSys.

**Tech Stack:** Node.js 22+, `node:sqlite`, `node:http`, Electron 39, HTML/CSS/JS, `node:test`, EventBus/outbox existente.

**Spec:** `docs/superpowers/specs/2026-09-09-e13-e20-design.md`

## Global Constraints

- Desktop local/LAN; sem SaaS/web como dependência operacional.
- UI nunca acessa SQLite diretamente.
- Dinheiro em centavos inteiros.
- Movimentos de estoque/caixa imutáveis.
- Efeitos externos fora da transação canônica da venda.
- Credenciais fiscais nunca expostas ao renderer.
- Migrations incrementais e não destrutivas.
- TDD obrigatório; suíte E01–E12 deve permanecer verde.
